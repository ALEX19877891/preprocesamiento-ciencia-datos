## 1. Introducción
En esa tarea se pudo practicar el uso de Git,  GitHub y visual studio Code, mediante la implementacion de procesos  para la creacion de repositorios, configuracion de archivos realizar commit, clonacion y configuracion, creacion y gestion de ramas y el pull request y fusion con esto vemos un paso a paso del manejor y beneficios de usar github.

## 2. Objetivo
Crear un sistema de preprocesamiento de datos que incluya limpieza, transformación.

## 3. Herramientas utilizadas
- Git: sistema de control de versiones para gestionar cambios en el código.
- GitHub: plataforma para almacenar y compartir repositorios en la nube.
- Visual Studio Code: editor de código utilizado para desarrollar el proyecto.
-

## 4. Comandos Git Utilizados
| Comando | Descripción |
|--------|------------|
| git clone | Clona un repositorio remoto a local |
| git add | Agrega archivos al área de preparación |
| git commit | Guarda los cambios con un mensaje |
| git push | Sube los cambios a GitHub |
| git checkout | Cambia de rama |
| git branch | Lista o crea ramas |
| git merge | Fusiona ramas |

## 5. Flujo de Trabajo
1. Se creó el repositorio en GitHub.
2. Se clonó el repositorio en Visual Studio Code.
3. Se configuró el usuario de Git.
4. Se creó una rama llamada `feature-preprocesamiento`.
5. Se desarrolló el archivo `preprocesamiento.py`.
6. Se realizaron commits y push.
7. Se creó un Pull Request en GitHub.
8. Se simuló la revisión.
9. Se fusionaron los cambios con la rama principal.
